Magnitude offsets

Offset = measured limit − predicted limit, at the same exposure and S/N. Example: 17.20 − 17.50 = −0.30 mag. Positive offsets move the limit fainter. Blank fields inherit the reference offset; 0.00 explicitly applies no correction.

No magnitude offsets applied.

The reference offset is a common magnitude correction for unmeasured bands, not an independent filter calibration. Corrections update curves, cursor S/N, errors and exposure recommendations. Sky background remains separately controlled. Use measurements representative of your observing conditions. Offsets are remembered in this browser when local storage is available.

Photometry standards and limitations

The cursor shows approximate 1σ uncertainty based on 1.085736/SNR for the source alone; differential error also includes the selected comparison-star S/N. The first-order magnitude error becomes asymmetric at low S/N and excludes calibration/systematic effects. The plot models a single image, not stacked-frame precision. The clear (L) band is an instrumental band, not a standard calibrated magnitude system. Standard photometry requires calibrated images, appropriate comparison stars, colour transformation where necessary, verified detector linearity and reported measurement uncertainty.

Equations, provenance and references

For a Gaussian stellar PSF, stellar electrons in the aperture are S = k₀ × 10^(−0.4m) × t × E(r), where E(r) = 1 − exp[−r²/(2σ²)]. The model solves q = S/√(S + C), with C = (Nₐ + Nₐ²/Nsky)×[(Bpix + Dpix)t + RN²]. The sky-annulus term is set to zero in archived-graph mode. At selected q, the limiting stellar signal is S = ½[q² + √(q⁴ + 4q²C)]. Bright saturation occurs when the modeled peak pixel reaches the camera full well after addition of sky and dark background.

Measured detector inputs: Mode 1/Gain 0, RN = 3.56 e⁻, full well = 50,462 e⁻, dark = 0.00156 e⁻/pix/s at −10°C; Mode 1/Gain 56, RN = 1.66 e⁻, full well = 21,626 e⁻, dark = 0.001641; Gain 58, RN = 1.59 e⁻, full well = 20,971 e⁻, dark = 0.001575 (Rossi, 2021). Pixel pitch 3.76 µm; focal length 1330 mm. Assumed optical obstruction 120 mm; assumed Gaussian FWHM 2.5″; default aperture radius = 6 native pixels (3.48″ at the default 0.58″/pixel). User-editable image scale is applied to pixel area, sky counts, peak-pixel fraction, and aperture encircled energy. This assumes independent native pixels; resampled or binned images require additional treatment.

Uncalibrated modeling inputs: nominal zero-magnitude integrated photon fluxes (B/V/R/I/L: 8.7/8.8/11/12.5/26 × 10⁹ photons m⁻² s⁻¹); effective system throughput (B/V/R/I/L: 0.36/0.41/0.42/0.32/0.55); sky magnitudes at clear = 18.0 (B/V/R/I/L: 19.11/18.31/18.01/16.81/18.00 mag arcsec⁻²). Other sky brightness values shift all five sky magnitudes by the same amount. These assumptions were carried forward solely for numerical continuity with the earlier S/N = 30 graph. Their absolute photometric zero-points have not been empirically validated at Flarestar.
